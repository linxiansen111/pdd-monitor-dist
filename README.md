# PddMonitor Distribution / 拼多多价格监控台分发

本仓库只承载安装包与版本号（Releases），**不含任何源码**。源码在私有仓库。

## 下载
到 [Releases](../../releases) 页面取最新版：

- `PddMonitor-x.y.z-setup.exe`：安装版（简体中文向导，装完双击即用）
- `PddMonitor-x.y.z-portable.zip`：便携版（解压即用，免安装）

两版均内置精简 MySQL：首次启动自动初始化数据库，无需安装 Python / Node / MySQL。

## 更新
程序内「更多操作 → 检查更新」可一键检测并升级到最新 Release。
